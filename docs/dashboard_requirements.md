# Dashboard Requirements

## Audience

NHS operational managers, elective recovery teams, healthcare analysts, and data analyst hiring reviewers.

## Dashboard Pages

1. Executive Overview
2. Trust Pressure
3. Specialty Performance
4. Regional Variation
5. Monthly Trend
6. Long-Waiter Recovery Queue

## KPIs

- Total waiting list
- 18-week performance
- Patients waiting 52+ weeks
- Long-waiter share
- Median wait weeks
- Trusts below 60% 18-week performance
- Highest pressure specialty

## Required Slicers

- Month
- Region
- Trust
- Specialty
- Pressure band
- Recovery priority

## Acceptance Criteria

- Total waiting-list numbers reconcile to raw input.
- 18-week performance uses total waiting list as denominator.
- Long-waiter share uses total waiting list as denominator.
- Dashboard separates trust, specialty, region, and trend views.
