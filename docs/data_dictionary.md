# Data Dictionary

| Field | Description |
| --- | --- |
| month | Reporting month |
| region | NHS region |
| trust_code | Synthetic trust code |
| trust_name | Trust name |
| specialty | Treatment specialty |
| total_waiting_list | Total incomplete RTT pathways |
| within_18_weeks | Pathways within 18 weeks |
| waiting_18_to_52_weeks | Pathways waiting between 18 and 52 weeks |
| waiting_52_plus_weeks | Pathways waiting 52 weeks or more |
| median_wait_weeks | Median wait in weeks |
| performance_18_weeks | Share of pathways within 18 weeks |
| long_waiter_share | Share of pathways waiting 52+ weeks |
| pressure_band | Operational pressure band created by this project |
| recovery_priority | Recommended recovery priority |
